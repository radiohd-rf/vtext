существующего TTS-плеера, который читает текст. Статусы: ✅ сделано, 🚧 в работе,
⏳ запланировано, 💤 отложено.

## 1. Задача и границы

**Задача.** Слушать в приложении готовые аудиокниги (файлы), с точной регулировкой
скорости, главами, таймером сна и продолжением с места остановки.

**Почему отдельно от TTS.** Сейчас `PlaybackCoordinator` управляет очередью
*текстовых фрагментов*: единица воспроизведения — абзац, позиция — `chapter:segment`,
скорость применяется к синтезу. У аудиофайла единица — время в миллисекундах,
скорость применяется к декодеру. Смешивать эти модели в одном классе значит получить
два набора ветвлений в каждом методе.

**В скоупе:**
- импорт аудиокниг (один файл или несколько файлов одной книги);
- воспроизведение, пауза, перемотка ±15/30 с, переход по главам;
- скорость 0,5×–2,0×: шаг 0,1, а в зоне 0,85–1,15 — **0,01**, с сохранением высоты голоса;
- главы: из файлов книги, из встроенных меток или одна общая;
- продолжение с места остановки, прогресс в библиотеке;
- фоновое воспроизведение, уведомление, управление с наушников;
- таймер сна, закладки по времени.

**Вне скоупа:**
- скачивание аудиокниг из сети, каталог, магазин;
- эквалайзер, нормализация громкости, выравнивание между файлами;
- синхронный показ текста при прослушивании (это отдельная большая задача);
- автоматическое распознавание «где чья реплика» и разделение по дикторам.

**Ключевое ограничение.** Текстовая (TTS) ветка не должна пострадать: её поведение,
классы и сохранённый прогресс остаются прежними.

## 2. Что меняется в модели данных

`Book` получает вид книги. Остальные поля остаются.

```kotlin
enum class BookKind { TEXT, AUDIO }

data class Book(
    val id: String,
    val title: String,
    val author: String?,
    val kind: BookKind = BookKind.TEXT,
    val format: BookFormat? = null,      // для AUDIO — null или формат первого файла
    ...
)
```

Для аудиокниги главы описываются дорожками, а не сегментами текста:

```kotlin
/** Одна дорожка аудиокниги: файл + время начала внутри файла. */
data class AudioChapter(
    val title: String,
    val filePath: String,     // абсолютный путь в filesDir/audio/<id>/
    val startMs: Long = 0,
    val durationMs: Long,
)

/** Состояние аудиоплеера — отдельный тип, не смешивается с PlayerState. */
data class AudioPlayerState(
    val bookId: String? = null,
    val title: String? = null,
    val author: String? = null,
    val chapters: List<AudioChapter> = emptyList(),
    val chapterIndex: Int = 0,
    val positionMs: Long = 0,
    val durationMs: Long = 0,
    val isPlaying: Boolean = false,
    val speed: Float = 1f,
    val isFinished: Boolean = false,
    val sleepTimerMinutes: Int? = null,
    val sleepUntilChapterEnd: Boolean = false,
    val bookmarks: List<AudioBookmark> = emptyList(),
    val error: String? = null,
)
```

**Миграция.** `meta.json` получает поле `kind`; у старых книг оно отсутствует → читаем
как `TEXT`. Файлы `chapters.json` для аудиокниг не создаются, вместо них `tracks.json`.

## 3. Форматы и движок воспроизведения

**Движок: `androidx.media3` (ExoPlayer + MediaSession).**

| Формат | Контейнер | Кодек | Поддержка |
|---|---|---|---|
| MP3 | .mp3 | MPEG-1/2 Layer III | встроенная |
| M4A / AAC | .m4a, .m4b | AAC-LC, HE-AAC | встроенная |
| FLAC | .flac | FLAC | встроенная (с API 21 через extractor) |
| OGG / Opus | .ogg, .opus | Vorbis, Opus | встроенная |
| WAV | .wav | PCM 16/24-bit | встроенная |
| AIFF | .aiff | PCM | через extractor платформы, 💤 не гарантируем |

Выбор ExoPlayer, а не `MediaPlayer`:
- встроенное сохранение высоты голоса при изменении скорости (Sonic);
- нормальная работа с несколькими файлами как одной очередью без щелей;
- `MediaSessionService` из коробки: уведомление, наушники, Bluetooth, Android Auto-совместимо;
- позиция и длительность в мс без «пляски» вокруг `MediaPlayer.getCurrentPosition()`.

**Отдельный сервис.** `AudioPlaybackService : MediaSessionService`. Существующий
`PlaybackService` (TTS) остаётся как есть. Два сервиса не конфликтуют: каждый держит
свою сессию, одновременно активна только одна — при запуске аудио TTS-плеер ставится
на паузу и наоборот.

**Формат по умолчанию.** При импорте определяем по расширению; при несовпадении
контейнера и расширения — по MIME из `ContentResolver`.

## 4. Тонкая настройка скорости

**Диапазон:** 0,50×–2,00×.

**Шаг — переменный:**

| Диапазон | Шаг | Пример |
|---|---|---|
| 0,50 – 0,85 | 0,10 | 0,7 · 0,8 |
| **0,85 – 1,15** | **0,01** | 0,93 · 1,05 · 1,12 |
| 1,15 – 2,00 | 0,10 | 1,3 · 1,6 · 2,0 |

Правила:
1. Скорость задаётся через `Player.setPlaybackSpeed(value)` — ExoPlayer сохраняет
   высоту голоса.
2. Вся логика шага — в одном месте, `SpeedPolicy`:
   ```kotlin
   object SpeedPolicy {
       const val MIN = 0.50f
       const val MAX = 2.00f
       const val FINE_FROM = 0.85f
       const val FINE_TO = 1.15f
       const val FINE_STEP = 0.01f
       const val STEP = 0.10f

       fun isFine(value: Float): Boolean = value in FINE_FROM..FINE_TO

       /** Шаг для текущего значения: от него считают кнопки «−/+». */
       fun stepFor(value: Float): Float =
           if (isFine(value)) FINE_STEP else STEP

       /** Округление к сетке и ограничение диапазоном. */
       fun snap(value: Float): Float = when {
           value < FINE_FROM -> roundTo(value, STEP).coerceAtLeast(MIN)
           value > FINE_TO -> roundTo(value, STEP).coerceAtMost(MAX)
           else -> roundTo(value, FINE_STEP).coerceIn(FINE_FROM, FINE_TO)
       }

       fun next(value: Float, direction: Int): Float =
           snap(value + direction * stepFor(value))

       /** «1.15×», «0.7×» — лишний ноль не выводим. */
       fun format(value: Float): String
   }
   ```
3. Цена границы: между 0,80 и 0,85 прыжок 0,05 — это осознанно. Альтернатива
   (шаг 0,01 по всему диапазону) даёт 150 позиций и превращает шкалу в ювелирную работу.
4. **Глобальная скорость** — значение по умолчанию для новых аудиокниг;
   **скорость книги** — переопределение, как уже сделано для TTS
   (`BookSettingsStore.speed(bookId)`).
5. Изменение скорости не сбрасывает позицию и не прерывает воспроизведение.
6. Экран не закрывается после выбора: можно сравнить темп на слух.

**UI шторки скорости** (единый компонент с TTS-плеером, `SpeedSheet`):
- горизонтальная шкала 0,5–2,0; шкала **непрерывная**, значение привязывается к сетке
  `snap()` на отпускании (иначе перетаскивание «залипает» на границе зоны);
- крупное текущее значение («1.15×») и подпись «шаг 0,01 в зоне 0,85–1,15»;
- кнопки «−» и «+» с шагом из `stepFor()` (touch-зона ≥ 48 dp); долгое нажатие
  повторяет шаг каждые 120 мс;
- **пресеты:** 0,75 · 0,85 · 0,90 · 1,00 · 1,10 · 1,15 · 1,25 · 1,50;
- сброс на 1,00×.

**Почему переменный шаг.** За пределами ±15% от единицы разница в 0,01 неслышна, зато
требует точности пальца. А вокруг 1,0 как раз и происходит подбор комфортной скорости:
1,03 против 1,07 — уже заметно на длинном прослушивании.

## 5. Экран плеера

Композиция — та же «Тёплая бумага», что в TTS-плеере: кремовая основа, антиква в
заголовках, бирюза в акценте, латунь в прогрессе.

```
┌──────────────────────────────────────┐
│  ←   Глава 3 из 12            ⋮      │   топбар
│                                      │
│        ┌────────────────┐            │
│        │                │            │   обложка 2:3,
│        │     обложка    │            │   скругление 12 dp
│        │                │            │
│        └────────────────┘            │
│     Мастер и Маргарита               │   headlineSmall, serif
│     Михаил Булгаков                  │   bodyMedium, inkSoft
│     Глава 3 · Понтий Пилат           │   labelLarge, teal
│                                      │
│   ────────●──────────────────        │   прогресс по книге
│   12:04            1:42:37           │   время главы
│                                      │
│      ⟲15      ▶/⏸     30⟳            │   транспорт
│                                      │
│  [ 1.15× ]  [ Главы ]  [ Сон ]  [ 🔖 ]│  капсулы
└──────────────────────────────────────┘
```

Требования:
1. Прогресс — по текущей дорожке; при перетаскивании показываем целевую позицию
   (`12:04 → 15:20`), перемотка применяется на отпускании, чтобы не дёргать декодер.
2. Кнопка play/pause — 68 dp, остальные 48 dp; при `isFinished` play превращается в
   «Начать заново».
3. Свайп по обложке влево/вправо — переход между главами (опционально, ⏳).
4. Клик по названию главы открывает список глав.
5. Ландшафт и планшет (ширина ≥ 840 dp) — две колонки: слева обложка и прогресс,
   справа управление и список глав.
6. Поддержка системного масштаба шрифта до 1,3 без обрезки.
7. Тёмная тема — из существующей палитры, без отдельных цветов.

## 6. Главы и навигация

Три источника, по приоритету:

1. **Несколько файлов** (папка или мультивыбор при импорте) — каждая дорожка = глава,
   название из метаданных (`title`) или из имени файла (`.mp3`/номер отбрасываются).
2. **Встроенные главы одного файла**: ID3v2 `CHAP`/`CTOC` для MP3, QuickTime chapters
   для M4A/M4B. Извлекаем при импорте в `tracks.json`.
3. **Одна глава** на весь файл, если меток нет. Название — «Глава 1» или имя файла.

💤 Автоматическое деление по тишине (энергия ниже порога дольше 1,5 с) — следующий этап;
на устройстве это ~1 минута обработки на час аудио (замерено на Python-пайплайне).

Навигация:
- «следующая/предыдущая глава» листает дорожки;
- при переходе через границу дорожки позиция = 0 новой дорожки;
- «предыдущая глава» на первых 3 секундах — переход на предыдущую, иначе в начало текущей
  (стандартное поведение плееров);
- перемотка ±15 с не перескакивает границу дорожки, а продолжает на следующей.

## 7. Импорт и хранение

**Импорт через SAF** (`OpenMultipleDocuments`, типы `audio/*`):
1. Пользователь выбирает один или несколько файлов.
2. Если файлов больше одного — показываем диалог «Это одна книга?» с подтверждением
   (по умолчанию «да»); при отказе каждая дорожка становится отдельной книгой.
3. Файлы **копируются** в `filesDir/audio/<id>/NN - название.ext` — как сейчас
   делается с текстовыми книгами: источник может исчезнуть, доступ по SAF нестабилен.
4. Название книги — из метаданных первого файла, иначе из имени файла;
   автор — из метаданных, иначе пусто.
5. Обложка — из встроенной картинки (ID3 APIC / MP4 `covr`), иначе типографская
   заглушка, как у текстовых книг.
6. Длительность дорожек — через `MediaMetadataRetriever` при импорте и кэшируется
   в `tracks.json` (иначе библиотека тормозит на открытии).

**Ограничения:**
- максимальный размер файла не ограничиваем, но предупреждаем, если свободного места
  меньше суммы размеров файлов ×2;
- дубликаты определяем по имени и размеру, спрашиваем «добавить всё равно?».

## 8. Фоновое воспроизведение

- `AudioPlaybackService` типа `mediaPlayback`, `MediaSession` с очередью `MediaItem`.
- Уведомление: play/pause, ±15 с, следующая/предыдущая глава, название и глава,
  обложка. Кнопка скорости — 💤 (в уведомлении тесно, а случайное нажатие портит темп).
- `setShowBadge`, `setSessionActivity` → открытие плеера этой книги.
- `AudioAttributes` = `USAGE_MEDIA`, `CONTENT_TYPE_SPEECH`.
- Аудиофокус: при потере — пауза, при возврате — не возобновляем самовольно
  (или возобновляем, если пауза была из-за кратковременного прерывания — решаем на этапе
  реализации, по умолчанию «не возобновлять»).
- Наушники выдернуты — пауза (`becomingNoisy`).
- Android 14: `FOREGROUND_SERVICE_MEDIA_PLAYBACK` уже объявлен в манифесте.

## 9. Библиотека

- Аудиокниги показываются в той же сетке; на обложке — маленький значок наушников.
- Прогресс — «Глава 3 из 12» и полоска по времени.
- Сортировка и поиск работают по тем же полям (название, автор).
- Долгое нажатие: удалить, «Переименовать» (⏳).
- Нажатие открывает `AudioPlayerScreen`; если книга `TEXT` — существующий `BookScreen`.

## 10. Сохранение прогресса и настроек

`AudioProgressStore` (SharedPreferences, ключ `pos_<bookId>`):
- сохраняем `chapterIndex` и `positionMs` каждые 5 секунд при воспроизведении,
  на паузе, при уходе из приложения и перед остановкой сервиса;
- при открытии: `position = positionMs - 3000` (небольшой откат, чтобы вспомнить контекст),
  но не меньше 0;
- «книга закончена», если позиция в последней дорожке больше `duration - 5 с`;
  тогда play показывает «Начать заново».

`AudioSettingsStore`:
- глобальная скорость (по умолчанию 1,00×);
- скорость книги (переопределение);
- таймер сна не сохраняется между запусками (как в TTS-плеере).

## 11. Таймер сна, закладки, Edge cases

**Таймер сна.** Те же варианты: «Выключен / До конца главы / 15 / 30 / 60 мин».
«До конца главы» = конец текущей дорожки. За 15 секунд до конца — плавное затухание
до нуля (300 мс шаг, 1,5 с), затем пауза.

**Закладки** по времени: сохраняем `chapterIndex + positionMs + метка` (первые 40 символов
названия главы или «12:34»), переход по нажатию, удаление свайпом.

**Edge cases:**
| Ситуация | Поведение |
|---|---|
| Файл повреждён/не читается | Сообщение «Не удалось воспроизвести файл», переход к следующей главе |
| Файл удалён из хранилища | Книга остаётся в библиотеке с пометкой «файл недоступен» |
| Нет прав на уведомления | Воспроизведение работает, уведомления нет (как в TTS) |
| Звонок во время прослушивания | Пауза, после звонка не возобновляем |
| Одновременно играет TTS-книга | TTS ставится на паузу при старте аудио и наоборот |
| Скорость 2,0× на дешёвом устройстве | Допустимо: Sonic работает на CPU, но проверить на Redmi Note 13 Pro |
| Дорожка короче 3 секунд | «Предыдущая глава» всегда листает назад |

## 13. Тестирование

**Юнит-тесты:**
- `SpeedPolicy.snap`: границы зоны (0,84 → 0,8; 0,85 → 0,85; 1,15 → 1,15; 1,16 → 1,2),
  округление до 0,01 внутри зоны и до 0,1 снаружи, ограничение 0,5 и 2,0;
- `SpeedPolicy.next`: шаг 0,01 на 1,00 → 1,01; шаг 0,1 на 1,30 → 1,40; переход
  через границу зоны (1,14 → 1,15 → 1,2);
- `SpeedPolicy.format`: «1.15×», «0.7×», «2×» без лишних нулей;
- выбор названия главы из имени файла (`03 - Понтий Пилат.mp3` → «Понтий Пилат»);
- разбор `tracks.json` и миграция `meta.json` без `kind`;
- расчёт прогресса книги по сумме дорожек и текущей позиции.

**Инструментальные (Robolectric или устройство):**
- импорт двух файлов → одна книга с двумя главами;
- перезапуск приложения → позиция восстановлена с откатом 3 с;
- смена скорости не сбрасывает позицию;
- переход через границу дорожки при перемотке.

**Ручная проверка на устройстве:** MP3, M4A, FLAC, OGG/OPUS, WAV; скорость 0,50 и 2,00,
а также 0,99 / 1,00 / 1,01 (шаг 0,01); наушники; звонок; блокировка экрана; поворот;
масштаб шрифта 1,3.

## 14. Этапы

| Этап | Что входит | Оценка |
|---|---|---|
| **1. Основа** | модель `BookKind`, `AudioRepository`, импорт, ExoPlayer, прогресс, экран плеера, скорость | ~3 дня || **2. Главы** | дорожки как главы, список глав, встроенные метки (ID3/MP4) | ~1,5 дня |
| **3. Фон** | `MediaSessionService`, уведомление, наушники, аудиофокус | ~1 день |
| **4. Комфорт** | таймер сна с затуханием, закладки, значок в библиотеке | ~1 день |
| **5. Плюс** | 💤 авто-деление по тишине, переименование, сортировка дорожек | — |

**Критерии готовности этапа 1:**
- аудиокнига импортируется и играет без заиканий на 0,50×, 1,00× и 2,00×;
- скорость меняется шагом 0,01 в зоне 0,85–1,15 и шагом 0,1 вне её, позиция не сбрасывается;
- после перезапуска приложения воспроизведение продолжается с того же места;
- TTS-плеер работает как раньше, регрессий нет.
