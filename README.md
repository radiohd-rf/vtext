# vtext

Android-приложение, которое читает вслух текстовые файлы и книги, загруженные пользователем, с помощью TTS (text-to-speech).

UX-референс — плеер Яндекс Книг, но только для случая, когда книгу ещё никто не озвучил: приложение само синтезирует речь из текста на устройстве.

## Возможности

- Импорт книг в форматах **TXT, FB2, EPUB, PDF, DOCX** через системный выбор файлов (SAF).
- Копирование книги в приватное хранилище приложения.
- Разбор на главы и короткие фрагменты для озвучивания (PDF — по встроенному оглавлению, при его отсутствии по размеру/жирности шрифта; DOCX — по заголовкам; фрагменты — по абзацам, без разрыва слов и обычных предложений).
- Очистка текста при импорте PDF/TXT: номера страниц, повторяющиеся колонтитулы, переносы слов, мусорные глифы символьных шрифтов.
- Пресеты импорта: «Авто», «Книга», «Стихи» — разная нарезка для прозы и стихов.
- Обложки книг в библиотеке, alt-текст изображений (EPUB/DOCX), подписи к рисункам не озвучиваются.
- Плеер: play/pause, переход по фрагментам и главам, оглавление.
- Экран текста с подсветкой текущего фрагмента.
- Скорость воспроизведения 0.75×–2× (сохраняется между сессиями), таймер сна.
- Сохранение прогресса и возобновление с начала главы, на которой остановились.
- Обработка конца книги: сообщение «Книга дочитана» и запуск заново.
- Фоновое воспроизведение: foreground-сервис, уведомление с play/pause/перемоткой, управление с экрана блокировки и наушников.
- Выбор русского голоса TTS в настройках (только русские голоса).
- Нейросетевой движок **Silero v5** (5 голосов, автоударения, «ё», омографы по контексту, эмфаза). Модель импортируется zip-архивом (см. `tools/silero/`).
- Разделение нейроголосов на мужские и женские, прослушивание короткого примера при выборе голоса.
- Эмфаза: курсив/жирный в EPUB, FB2 и DOCX и слова КАПСОМ читаются с нажимом.
- Паузы: многоточия, тире, двоеточия, переносы строк в стихах, а также SSML `<break time="2s"/>` и `<p>/<s>`.
- Настройки звучания: громкость, тон (системный TTS), пауза между фрагментами.
- Удаление книги долгим нажатием в библиотеке.

План улучшений и статусы — `docs/SPEC.md`.

## Сборка

```powershell
.\gradlew.bat :app:assembleDebug       # APK в app/build/outputs/apk/debug/
.\gradlew.bat :app:testDebugUnitTest   # юнит-тесты
.\gradlew.bat :app:installDebug        # установка на устройство
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Silero v5

Модель Silero не скачивается приложением: PyTorch-пакет нужно один раз сконвертировать в `.ptl` и импортировать в настройках.

```powershell
python -m pip install torch
python tools/silero/export_silero.py            # скачает v5_6_ru.pt и соберёт build/silero/silero-5-ru.zip
```

Затем: Настройки → **Silero v5** → **Импорт** → выбрать `silero-5-ru.zip`. Файлы распакуются в `filesDir/tts/silero-5-ru`.

В архив также входит словарь ударений **RUAccent** (MIT, © Denis Petrov; текст лицензии — `tools/silero/LICENSE-ruaccent.txt`): 3,19 млн словоформ в компактном виде (27 МБ), точное ударение подставляется раньше нейросети. Собрать архив без него: `python tools/silero/export_silero.py --no-stress`.

Контекст для омографов (`за́мок`/`замо́к`, `сто́ит`/`стои́т`) даёт модель **homosolver** из Silero: 37 МБ + фразовые правила (`phrases.json`). Отключить: `--no-homosolver`. Итоговый архив — около 132 МБ, после импорта на диске ~166 МБ.

Лицензия модели Silero v5 — **CC BY-NC 4.0** (некоммерческое использование).

### Словарь произношения

Английские слова Silero не читает (в словаре модели только кириллица), поэтому они транслитерируются автоматически. Свои варианты можно задать файлом:

```
# слово=произношение
python=пайтон
kubernetes=кубернетес
замок=з+амок
# фраза целиком — для омографов, где важен контекст
на замок=на зам+ок
старинный замок=старинный з+амок
```

Настройки → **Silero v5** → **Словарь произношения** → **Импорт словаря**. Знак `+` задаёт ударение; словарь применяется сразу, без перезапуска.

## Структура

```
app/src/main/java/ru/vtext/app/
├── data/        # библиотека книг, прогресс, настройки TTS
├── domain/      # модели, сегментация текста, парсеры TXT/FB2/EPUB/PDF/DOCX
├── player/      # координатор воспроизведения и foreground-сервис
├── tts/         # системный TTS, SileroSpeechEngine, TtsManager, импорт моделей
├── ui/          # экраны библиотеки, плеера и настроек, тема
├── MainActivity.kt
└── VtextApp.kt
```
