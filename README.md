# vtext

Android-приложение, которое читает вслух текстовые файлы и книги, загруженные пользователем, с помощью TTS (text-to-speech).

UX-ориентир — современные аудиоплееры книг, но только для случая, когда книгу ещё никто не озвучил: приложение само синтезирует речь из текста на устройстве.

## Возможности

- Импорт книг в форматах **TXT, FB2, EPUB, PDF, DOCX** через системный выбор файлов (SAF).
- **Аудиокниги**: локальные файлы (MP3, M4A, FLAC, OGG/OPUS, WAV) и **онлайн-книги
  из публичной папки Яндекс.Диска** — файлы не скачиваются, плеер стримит их напрямую.
  При открытии книги папка перечитывается, поэтому новые файлы подхватываются.
- Добавление — одной шторкой по кнопке «Добавить книгу»: печатная книга,
  аудиокнига с телефона или аудиокнига по ссылке Яндекс.Диска.
- **Читалка**: тап по текстовой книге открывает чтение — прокрутка, три темы
  (бумага, сепия, ночь), шрифт с засечками/без, размер, межстрочный интервал,
  поля и яркость, оглавление, закладки. Оглавление — в шапке справа; под ней
  справа строка действий: фиксация ориентации экрана, оригинал PDF, «Слушать»,
  оформление, закладки. Прослушивание продолжается с текущего абзаца;
  прогресс общий с плеером.
- При первом запуске в библиотеку автоматически добавляются две онлайн-книги:
  «СФ Мастер и Маргарита» (19 частей) и «Лучко Клара — Я — счастливый человек»
  (132 части). Списки дорожек вшиты в APK, звук стримится с Яндекс.Диска,
  книги можно удалить — повторно они не добавятся.
- Копирование книги в приватное хранилище приложения.
- Разбор на главы и короткие фрагменты для озвучивания (PDF — по встроенному оглавлению, при его отсутствии по размеру/жирности шрифта; DOCX — по заголовкам; фрагменты — по абзацам, без разрыва слов и обычных предложений).
- Очистка текста при импорте PDF/TXT: номера страниц, повторяющиеся колонтитулы, переносы слов, мусорные глифы символьных шрифтов.
- PDF в читалке: абзацы восстанавливаются по вёрстке (отступ первой строки, короткая строка, увеличенный интервал), стихи распознаются по длине строк и сохраняют строфы, сноски внизу страницы не читаются.
- Переключатель «Оригинал PDF» в читалке: страницы рендерятся как в файле (PdfRenderer) и открываются на странице текущей главы; кнопка «Текст» возвращает в обычное чтение.
- Оригинал PDF: масштаб щипком двумя пальцами или двойным тапом (до 400 %), кнопка «По ширине» ставит страницу по ширине экрана. Замок фиксирует текущий масштаб и горизонтальный сдвиг: при вертикальной прокрутке вид не уезжает вбок. Масштаб, замок и сдвиг запоминаются для книги до снятия замка.
- Пресеты импорта: «Авто», «Книга», «Стихи» — разная нарезка для прозы и стихов.
- Библиотека — компактный список с постерами 2:3: название, автор, плашка типа книги
  и процент прочитанного/прослушанного в углу постера. Поиск по названию и автору,
  сортировка, общее количество книг, «Добавить книгу» в шапке.
- Обложки книг в библиотеке, alt-текст изображений (EPUB/DOCX), подписи к рисункам не озвучиваются.
- Оформление: системная, светлая или тёмная тема, опционально цвета системы (Material You).
- Плеер TTS: play/pause, переход по фрагментам и главам, оглавление.
- Плеер аудиокниг: название книги в шапке, глава под обложкой, остаток «До конца книги» с учётом скорости, шторка «Содержание» с номером, названием, длительностью и размером главы (активная подсвечена), меню ⋮ с настройками плеера. Перемотка назад/вперёд настраивается на 15/30/60 секунд, интервал показан под иконкой.
- Экран текста с подсветкой текущего фрагмента и **текущего слова** (караоке-режим).
- Скорость воспроизведения 0.75×–2× (сохраняется между сессиями), таймер сна.
- Сохранение прогресса и возобновление с начала главы, на которой остановились.
- Обработка конца книги: сообщение «Книга дочитана» и запуск заново.
- Фоновое воспроизведение: foreground-сервис, уведомление с play/pause/перемоткой, управление с экрана блокировки и наушников.
- Выбор русского голоса TTS в настройках (только русские голоса).
- Нейросетевой движок **Silero v5** (5 голосов, автоударения, «ё», омографы по контексту, эмфаза). Модель импортируется zip-архивом (см. `tools/silero/`).
- Разделение нейроголосов на мужские и женские, прослушивание короткого примера при выборе голоса.
- Эмфаза: курсив/жирный в EPUB, FB2 и DOCX и слова КАПСОМ читаются с нажимом.
- Паузы: многоточия, тире, двоеточия, переносы строк в стихах, а также SSML `<break time="2s"/>` и `<p>/<s>`.
- Настройки звучания: громкость, тон (системный TTS), пауза между фрагментами.
- Скорость и голос запоминаются для каждой книги отдельно, закладки с переходом к месту.
- Удаление книги долгим нажатием в библиотеке.
- При запуске приложение само проверяет новые версии на GitHub: если обновление
  есть, показывается окно с предложением скачать и установить; «Позже» скрывает
  его до следующего запуска, «Отмена» во время загрузки прерывает скачивание.

План улучшений и статусы — `docs/SPEC.md`.

## Статус

Собирается, 52 юнит-теста проходят. Проверено на смартфоне (Redmi Note 13 Pro): импорт TXT/DOCX/PDF, разбор глав, фоновое воспроизведение с уведомлением, конец книги, сохранение скорости и выбранного голоса, удаление книги, синтез Silero v5 и воспроизведение книги, ударения и омографы, предпросмотр голосов, очистка PDF от колонтитулов и номеров страниц, главы из PDF-закладок и по шрифту, пресеты импорта, обложки и alt-текст.

## Стек

Kotlin 2.0.21 · Jetpack Compose (Material 3) · Navigation Compose · MVVM · Android TTS · PyTorch Lite (Silero v5) · PDFBox-Android · minSdk 24 / targetSdk 35.

## Сборка

```powershell
.\gradlew.bat :app:assembleDebug       # APK в app/build/outputs/apk/debug/
.\gradlew.bat :app:testDebugUnitTest   # юнит-тесты
.\gradlew.bat :app:installDebug        # установка на устройство
```

APK: `app/build/outputs/apk/debug/app-debug.apk` (только `arm64-v8a`, ~88 МБ).

## Silero v5

Модель Silero не скачивается приложением: PyTorch-пакет нужно один раз сконвертировать в `.ptl` и импортировать в настройках.

```powershell
python -m pip install torch
python tools/silero/export_silero.py            # скачает v5_6_ru.pt и соберёт build/silero/silero-5-ru.zip
```

Затем: Настройки → **Silero v5** → **Импорт** → выбрать `silero-5-ru.zip`. Файлы распакуются в `filesDir/tts/silero-5-ru`.

В архив также входит словарь ударений **RUAccent** (MIT, © Denis Petrov; текст лицензии — `tools/silero/LICENSE-ruaccent.txt`): 3,19 млн словоформ в компактном виде (27 МБ), точное ударение подставляется раньше нейросети. Собрать архив без него: `python tools/silero/export_silero.py --no-stress`.

Контекст для омографов (`за́мок`/`замо́к`, `сто́ит`/`стои́т`) даёт модель **homosolver** из Silero: 37 МБ + фразовые правила (`phrases.json`). Отключить: `--no-homosolver`. Итоговый архив — около 132 МБ, после импорта на диске ~166 МБ.

Лицензия модели Silero v5 — **CC BY-NC 4.0** (некоммерческое использование).

### Словарь произношения

Английские слова Silero не читает (в словаре модели только кириллица), поэтому они транслитерируются автоматически. Свои варианты можно задать файлом:

```
# слово=произношение
python=пайтон
kubernetes=кубернетес
замок=з+амок
# фраза целиком — для омографов, где важен контекст
на замок=на зам+ок
старинный замок=старинный з+амок
```

Настройки → **Silero v5** → **Словарь произношения** → **Импорт словаря**. Знак `+` задаёт ударение; словарь применяется сразу, без перезапуска.

## Структура

```
app/src/main/java/ru/vtext/app/
├── data/        # библиотека книг, прогресс, настройки TTS
├── domain/      # модели, сегментация текста, парсеры TXT/FB2/EPUB/PDF/DOCX
├── player/      # координатор воспроизведения и foreground-сервис
├── tts/         # системный TTS, SileroSpeechEngine, TtsManager, импорт моделей
├── ui/          # экраны библиотеки, плеера и настроек, тема
├── MainActivity.kt
└── VtextApp.kt
```
