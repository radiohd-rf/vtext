# vtext

Android-приложение, которое читает вслух текстовые файлы и книги, загруженные пользователем, с помощью TTS (text-to-speech).

UX-референс — плеер Яндекс Книг, но только для случая, когда книгу ещё никто не озвучил: приложение само синтезирует речь из текста на устройстве.

## Возможности (план)

- Импорт текстовых файлов (книг) через системный выбор файлов.
- Озвучивание текста системным TTS-движком Android.
- Плеер в духе Яндекс Книг: прогресс по книге и главе, play/pause, перемотка.
- Оглавление, переход к главе, экран текста с подсветкой текущего фрагмента.
- Скорость воспроизведения (0.5×–3×), таймер сна.
- Сохранение прогресса и возобновление с места остановки.
- Фоновое воспроизведение с уведомлением.

## Статус

Каркас репозитория создан; Android-проект ещё не сгенерирован.
