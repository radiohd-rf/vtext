## Обзор проекта

- **Проект:** vtext
- **Платформа:** Android
- **Цель:** читать вслух загруженные пользователем текстовые файлы и книги с помощью TTS.
- **Дата создания:** 2026-11-06

## Функциональные требования

- Загрузка/выбор текстового файла (книги) пользователем.
- Озвучивание текста через системный TTS-движок Android.
- Управление воспроизведением: play / pause / resume / stop.
- Навигация по тексту (по главам/фрагментам/позиции).
- Сохранение прогресса чтения и возобновление с последней позиции.
- Настройки: скорость речи, язык/голос, пауза между фрагментами.
- Фоновое воспроизведение (желательно) — foreground service с уведомлением.

## Стек и архитектура

**Статус:** проект ещё не сгенерирован, стек предлагается (уточнить у владельца).

Предполагаемый стек:
- Язык: **Kotlin**.
- UI: **Jetpack Compose** + Material 3.
- Архитектура: MVVM, одноактивити, слои UI → ViewModel → domain → data.
- TTS: `android.speech.tts.TextToSpeech` за собственной обёрткой (интерфейс `SpeechEngine`).
- Файлы: Storage Access Framework (`ACTION_OPEN_DOCUMENT`, persistable URI permission).
- Состояние: `DataStore` (настройки, прогресс), `Room` — при необходимости библиотеки/закладок.
- Фон: `MediaSessionService`/foreground service для продолжения чтения в фоне.
- Асинхронность: корутины + Flow.

Принципы:
- TTS-движок изолирован интерфейсом — можно заменить или замокать.
- Текст заранее разбивается на предложения/абзацы; очередь фрагментов — единица воспроизведения и возобновления.
- Полный текст книги не держим в памяти целиком — читаем потоково, если файл большой.

## Грабли и известные проблемы

- Android TTS: `TextToSpeech` инициализируется асинхронно, статус приходит в `OnInitListener`; вызовы `speak()` до готовности игнорируются.
- `speak()` имеет лимит ~4000 символов на высказывание — длинный текст нужно резать.
- Нужно отслеживать `UtteranceProgressListener` для перехода к следующему фрагменту и прогресса.
- Doze/энергосбережение убивают фоновое чтение — нужен foreground service с уведомлением.
- SAF URI требует `takePersistableUriPermission`, иначе доступ теряется после перезапуска.
